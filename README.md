# QIDI Q2 + Box — учебник

Русскоязычный учебник с абсолютного нуля: распаковка, место и безопасность, PLA, первый слой, QIDI Box, слайсер, уход. Не энциклопедия по всем пластикам и не замена [wiki QIDI](https://wiki.qidi3d.com/en/Q2).

**Сайт:** https://sillyhatsonly.github.io/q2/  
**Версия:** v3.7.1 · 17 ноября 2026  
**Репозиторий:** [SillyHatsOnly/q2](https://github.com/SillyHatsOnly/q2)

Правки вносят в `index.html`. Markdown — сжатое зеркало; если правили только HTML, Markdown лучше синхронизировать перед следующим ревью.

## Как устроен курс

1. Понять оборудование (FDM, Q2, Box, штанген).
2. Подготовить место (вентиляция, розетка, кит инструментов, распаковка).
3. Напечатать (PLA, дверь/люк, ритуал, первый слой).
4. Обслуживать (пауза, аварии, уход, Box).
5. Материалы и слайсер → упражнения → курс Fusion (отдельный шаг).

В тексте бейджи: **Официально** / **Чаты** / **Позже** / **Делать сейчас**. Цифры прошивки и Studio живут неделями — перед обновлением сверяйте страницы QIDI.

## Публикация

Репозиторий отдаёт GitHub Pages из корня ветки `main` (файл `index.html`).

```bash
git add index.html
git commit -m "…"
git push origin main
```

Через минуту-две обновится https://sillyhatsonly.github.io/q2/. Жёсткое обновление в браузере, если видна старая версия.

## Локальный просмотр

Откройте `index.html` в браузере или поднимите простой сервер из корня репозитория:

```bash
python3 -m http.server 8080
```

Дальше: http://127.0.0.1:8080/

## Что не входит в публикацию

В рабочей папке могут лежать экспорты чатов, черновики ревью и прочие локальные материалы. На сайт и в GitHub они не обязаны попадать: для чтения учебника достаточно `index.html`, `guide/media/` и `media/`.

## Лицензии

Текст учебника — для учебного чтения; коммерческую перепечатку и правки крупных кусков согласуйте с автором репозитория. Картинки — по [SOURCES.txt](guide/media/SOURCES.txt): Wikimedia, wiki QIDI, Prusa KB и пользовательские снимки имеют разные условия. Чужие модели с Printables / MakerWorld — по лицензии автора модели, не «раз бесплатно — значит можно продавать».
