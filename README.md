# QIDI Q2 + Box — учебник

Русскоязычный учебник с абсолютного нуля: распаковка, место и безопасность, PLA, первый слой, QIDI Box, слайсер, уход. Не энциклопедия по всем пластикам и не замена [wiki QIDI](https://wiki.qidi3d.com/en/Q2).

**Версия:** v4.1.0 · 27 ноября 2026  
**Репозиторий:** [SillyHatsOnly/q2](https://github.com/SillyHatsOnly/q2)

## Как устроен курс

1. Понять оборудование (FDM, Q2, Box, штанген).
2. Подготовить место (вентиляция, розетка, кит инструментов, распаковка).
3. Напечатать (PLA, дверь/люк, ритуал, первый слой).
4. Обслуживать (пауза, аварии, уход, Box).
5. Материалы и слайсер → упражнения → курс Fusion (отдельный шаг).

Цветные плашки на странице: зелёная — делать, жёлтая — сверить с wiki, красная — стоп, синяя — короткий маршрут. Цифры прошивки и Studio живут неделями: перед обновлением откройте страницы QIDI ещё раз.

## Публикация

Репозиторий отдаёт GitHub Pages из корня ветки `main` (файл `index.html`).

```bash
git add index.html
git commit -m "…"
git push origin main
```

Через минуту-две обновится https://sillyhatsonly.github.io/q2/. Жёсткое обновление в браузере, если видна старая версия.

## Локальный просмотр

Откройте `index.html` в браузере или поднимите простой сервер из корня репозитория:

```bash
python3 -m http.server 8080
```

Дальше: http://127.0.0.1:8080/

## Что не входит в публикацию

В рабочей папке могут лежать экспорты чатов, черновики ревью и прочие локальные материалы. На сайт и в GitHub они не обязаны попадать: для чтения учебника достаточно `index.html`, `guide/media/` и `media/`.

## История версий

Номера ниже — те, что стояли в шапке `index.html`. Отдельных выпусков 3.1, 3.2 и 3.9.1 не было.

### v4.1.0 · 27 ноября 2026

Пилотный проход по живому русскому: «Первый вечер», «Как читать», лид, «Место и безопасность», лёгкая правка FDM/карточки питания. Убраны редакторские ремарки и повтор «слева направо» у галерей (номера в подписях остаются). Средство для посуды явно привязано к мытью листа PEI. В корне лежит `prose_lint.py` — грубый счётчик штампов до/после следующих глав.

### v4.0.1 · 22 ноября 2026

Сетка на средних экранах больше не сжимает оглавление. ASA/ABS в материалах и в листе готовности совпадают с требованием вытяжки наружу. Удлинитель — зона взрослого/электрика, не оценка кабеля новичком. Повтор куба — диапазон и несколько образцов, не вердикт «принтер неточный». Изопропанол в первой печати помечен как опция. Лайтбокс: вертикальное центрирование, ловушка фокуса и возврат на картинку. Мульти-галереи пронумерованы слева направо. Меню на мобилке без JS остаётся открытым; прогресс штангенциркуля отдаёт aria; `meta keywords` убран. В сетках картинок — одинаковая высота рамки превью: подписи в одном ряду стоят на одной линии, клик по-прежнему открывает полный кадр.

### v4.0.0 · 22 ноября 2026

Вёрстка «как для чтения»: оглавление слева, текст по центру экрана. Сетки картинок приведены к одному правилу — слева направо, сверху вниз, на десктопе две колонки, подписи с номерами. Убраны повторные галереи PTFE/силикагеля и коллаж Y-splitter. Шрифт без Iowan/Palatino: в Firefox кириллическая «о» больше не прыгает. Дублирующая схема штангенциркуля с немецкими подписями снята — остались фото и схема замеров. У PLA, PETG, ASA/ABS и TPU метки «Зачем» и «Когда» вынесены на отдельные строки, чтобы глаз цеплялся за левый край.

### v3.9.9 · 22 ноября 2026

Маршрут «Первый вечер» переехал под заголовок: около полутора часов, если прошивку обновлять не нужно. Распаковку пропускают, когда принтер уже стоит. Встроенная лодочка идёт из памяти, Studio нужна для своей модели. После места, распаковки, сети, лодочки и первого слоя стоит строка «можно дальше, если…».

Сушка в таблице начинается с цифры на этикетке. Расхождение быстрого старта Q2, Filament Guide и инженерного гайда осталось в сноске. Скорости подписаны как рекомендации быстрого старта, не потолок механики. Стол ASA — две разные рекомендации QIDI (90 °C и 100–110 °C), не один диапазон.

Box на первый PLA стоит сбоку, чтобы люк уезжал. Стяжки режут после подъёма стола. Стук сопла при автоуровне назван штатным. Лист PEI кладут до самотеста, хаб Box до него не подключают. Оранжевый силикагель, синий в кухонную духовку не кладут. Рядом с датчиком дыма — огнетушитель или полотно. Принтер включают в настенную розетку; Fluidd не выносят в гостевую сеть. Правило 45° одно: от плоскости стола.

В слайсер добавлены три кадра QIDI Studio с пометкой, что сняты они на Q1 Pro. Лайтбокс в режиме 1:1 больше не прячет край большой картинки. Чекбоксы помнят галочки по метке, тема ставится до отрисовки, есть favicon, у картинок прописаны ширина и высота. Рядом с курсом ИТМО стоят FreeCAD и Onshape; учебник к курсу отношения не имеет.

Поздний проход по рецензиям той же версии: «рядом взрослый» смягчён для взрослого новичка; изопропанол ушёл из обязательного списка; таблица «чуть позже» разделена на первый месяц и справочник; лист готовности — «к первой печати» и «итоги месяца»; сноски про стол 110/120 °C, ABS/ASA и вытяжку, LED как электронику; тёмная тема для рамок плашек; `aria-expanded` у оглавления; отступ подразделов в навбаре; checkpoint после слайсера.

Картинки — по [SOURCES.txt](guide/media/SOURCES.txt): Wikimedia, wiki QIDI, Prusa KB и пользовательские снимки имеют разные условия.
